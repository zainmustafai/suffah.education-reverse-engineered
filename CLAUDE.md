# How to use this repo (for Claude Code)

This repo documents how the Suffah Education web app behaves, screen by screen, so you can build similar software.

- Read `docs/00-overview.md` first: product map, roles, navigation.
- Each module has one doc in `docs/`. A module doc lists: purpose, routes, screens (with screenshot links), fields, actions, validations, empty/error states, and notes on behavior.
- End-to-end journeys live in `flows/` as numbered steps with screenshots.
- Screenshots are full HD and named `<module>/<nn>-<screen>.png`. Trust the doc text for behavior; use screenshots for layout and exact labels.
- `PROGRESS.md` shows coverage. Anything marked "not yet documented" is unknown — do not guess it.
- Data shown is realistic but fictional, created for this walkthrough. `CREATED_RECORDS.md` lists every created record.
