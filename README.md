# Suffah Education — Reverse-Engineered Reference

Reference walkthrough of [Suffah Education](https://www.suffah.education) for building similar software. The owner chose to keep this repository public: it holds documentation and screenshots only - no credentials and no real personal data.

This repo is written for Claude Code and other coding agents. It contains:

- `docs/` — one Markdown file per module/feature: what it does, the screens, the fields, the flow, the rules it follows.
- `flows/` — step-by-step user flows in Markdown, each step paired with a screenshot.
- `screenshots/` — 30 desktop page captures (print-layout renders), grouped by module. Three captures that contained the owner's real email/phone are blacked out.
- `PROGRESS.md` — what has been documented and what is left.
- `CREATED_RECORDS.md` — every record created inside Suffah during the walkthrough, for cleanup.

Start with `CLAUDE.md`, then `docs/00-overview.md`.
