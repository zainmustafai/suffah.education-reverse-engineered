# Learning Pathway

- Route(s): /tools/learning-pathway
- Roles that can see this: Manager (as observed)
- Screenshots: ../screenshots/learning-pathway/ (pending - batch 2)

## What it does
"Set the materials a class will study, in order." A class-level ordered reading list -
NOT per-student progress (no student appears anywhere on this page; progress surfaces, such
as they are, live in Student Analytics and the Interactive Qur'an browser).

## Screen
- CLASS combobox listing every class (grouped under "Quran School"): the 4 Hifz levels,
  3 Qur'an (Nazra) levels, Islamic Studies L1, Arabic L1 - 9 classes.
- Actions: "Copy" (disabled until a pathway exists; tooltip "Copy this pathway to other
  classes") and "My materials - N".
- Empty state: "No materials yet. Add the first one below."
- Add form: search/type box "Search my materials or type a new one...", "Pages" spinbutton,
  "Add material" button, "Save to my materials for reuse" checkbox (checked by default).

## My materials
- "Saved once, reusable in any class's pathway." New material form: Name ("book, juz,
  unit..."), Pages, Type (Qur'an / Book default / Juz / Unit / Surah / Worksheet / Other),
  Notes (optional - "edition, publisher..."), "Save material" (disabled until filled).
- Two built-in DEFAULT materials ship with the product: "Qur'an (by page)" - Qur'an,
  604 pages, Madani mushaf; "Qur'an (by juz)" - Qur'an, 30 juz, Al-Faatiha to An-Naas.
  Each has an "Add" button into the current class pathway.
- Nothing was added during this walkthrough; every class pathway in this school is empty,
  which Student Analytics confirms ("None of these classes has a learning pathway yet").
