## Admin - /tools/school-page
"Your public page. What's happening at the school, kept current for families and visitors."
Controls: "New update" button; tabs "Updates" and "Page info"; the public link
suffah.education/maddrassah/page with a Copy button.
- Updates tab empty state: "No updates yet - Post news, events and closures for families."
- New update editor (opened, then cancelled - nothing saved): note "Published updates appear
  on the public school page straight away." Buttons Cancel / Save draft / Publish. Fields:
  TYPE (combobox: Update default; Event; Closure; Notice), DATE SHOWN (pre-filled with
  today), TITLE (placeholder "e.g. Closed for Eid al-Adha"), DETAILS (placeholder "What
  families need to know..."), "Pin to the top of the page" switch (off), and a LIVE VIEW
  preview panel of the public news page.
- Page info tab: ABOUT THE SCHOOL, OPENING HOURS, ADDRESS, CONTACT text boxes and a
  "Save details" button. Caution: in the observed state the boxes showed what appear to be
  placeholder-style texts ("A short description of your school.", "Street, city, state ZIP",
  "office@school.edu - +1 (555) 000-0000") and Save was disabled; whether any real values are
  stored could not be confirmed. None of these four sections appeared on the public home page.
