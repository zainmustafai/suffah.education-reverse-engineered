# Realistic use cases used in this walkthrough

The walkthrough runs on realistic, complete scenarios — not dummy data.

## The institute (adapted to whatever the account already contains)
- A working Islamic school/madrasa: full-time Hifz and Nazra classes plus part-time evening/weekend classes.
- Classes with sections, class teachers, and subjects (Quran, Tajweed, Arabic, Islamic Studies, Maths, English).

## People
- Admin, teachers, students with siblings in different classes, and guardians with real relationships to students.
- Phone numbers, emails, and addresses in realistic formats. All fictional.

## Scenarios to run end to end
1. New admission: two siblings join, guardian linked once, sibling fee discount applied.
2. Attendance: a full class marked, with late arrivals and one absent-with-reason.
3. Fees: monthly invoice generated, partial payment recorded, one invoice goes overdue, reminder flow checked.
4. Exams: marks entered for a class, grades calculated, report card produced.
5. Timetable: a clash created and resolved; a teacher on leave and a substitution arranged.
6. Communication: an announcement/message sent to one class's parents.
7. Staff: teacher added with subjects and classes assigned.

Each scenario becomes a file in `flows/` with screenshots at every step.
