## Interactive Qur'an - /tools/interactive-quran -> redirects to /quran
- The header still carries the "In development" badge, but this is a WORKING browser, not a
  stub. Purpose: per-student Qur'an work tracking (Read / Memorize / Review; legend:
  "hollow assigned - filled graded").
- Left panel: "All Students" / "Current Student" tabs and a button per class showing
  program, shift, days/times and student count (e.g. Hifz L1 A - Morning - Mon-Fri
  09:00-12:00 - 1 student).
- Main panel: "Browse surahs" - "No student selected - pick one to see their work."
  Controls: "Select" button, "Search surah" box, "Filter" button. A grid of Juz 1-30 cards,
  each with its surah range and count (Juz 1: Al-Fatihah 1 - Al-Baqarah 141, 2 surahs;
  Juz 30: An-Naba 1 - An-Nas 6, 37 surahs).
- No student was selected in this walkthrough, so per-student assignment/grading screens
  remain undocumented - flagged as the one known coverage gap alongside assignment step 6.
