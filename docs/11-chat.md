# Chat

- Route(s): /chat
- Roles that can see this: Manager (as observed)
- Screenshots: ../screenshots/chat/chat.png
- This walkthrough was strictly read-only in Chat: nothing was typed or sent anywhere.

## Layout
- Messages pane (presence header "Online") + main pane. The pane has a search box,
  People / Groups tabs, a role filter (All Roles; also Admin, Manager, Parent, Student,
  Support, Teacher) and a status filter (Active).
- With nothing selected the main pane reads: "Welcome to Messages - Select a conversation
  from the sidebar to start chatting with your team members or groups."

## People
- "Recent contacts" initially shows ONLY the pinned entry "Platform Support - Unified
  Support" (avatar "S"). The directory is not browsable by default - people appear via search.
- Search works across the school's users: "Siddiqui" returned both Yusuf records, Maryam and
  Ahmed Raza; "Fatimah" returned Fatimah Zahra Sheikh. Roles are shown per result.

## Groups
- "Create New Group" button + search ("Search groups...").
- The product AUTO-CREATES groups: a "Managers" group (1 member), one group per class
  (e.g. "Arabic - Level 1 - Level 1 - Section A"), matching "Parents - ..." community groups
  per class ("Teachers and Managers can type"), a "Parents Community" (2 members), and
  "School Announcements" (7 members, "Managers can type"). Posting rights are baked into the
  group descriptions: parents are read-only in their class communities; announcements are
  manager-only.

## Thread view
- Header: avatar initial, name, presence (Platform Support showed "Offline").
- Empty state: "No messages yet / Start the conversation!"
- Composer: a single "Message..." field with a paper-plane send button (disabled while
  empty). No attachment or media controls were visible in the observed state.
- Verified identical for the Platform Support thread and a fictional user's thread
  (Maryam Ahmed Siddiqui) - both empty, nothing sent.

## Notes
- The duplicate Yusuf user appears in Chat search as two separate contacts, same as
  everywhere else in the product.
